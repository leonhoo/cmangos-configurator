# Cmangos Configurator

### 为了方便修改Cmangos服务的配置, 使用 Tauri 2 \+ React 构建的轻量级配置管理工具

**中文** | [English](./README.md)

---

## 功能特性

- 🖥️ **macOS 原生风格界面**，简洁美观

- 📝 **新建配置**：基于 YAML 模板生成默认配置

- 📂 **导入配置**：导入 `key=value` 格式配置文件并自动覆盖

- ✏️ **编辑配置**：弹窗编辑，支持多行描述，值高亮显示

- 💾 **另存为**：导出为标准 `key=value` 配置文件

- 🔍 **搜索筛选**：支持按分组、Key、Value、描述搜索

- 🌐 **多语言切换**：中文 / English 一键切换

- 📝 **操作日志**：导入、修改、保存均记录，错误标红

- 📦 **超轻量**：Tauri 2 构建，体积小、启动快

## 技术栈

- **前端**：React \+ JavaScript

- **桌面端**：Tauri 2 \(Rust\)

- **文件处理**：YAML、Tauri FS / Dialog 插件

- **多语言**：i18next

## 界面预览

- 主界面：新建 / 导入配置

- 配置列表：分组展示，Key 左、Value 高亮右对齐

- 编辑弹窗：清晰排版，支持多行描述

- 日志面板：暗色主题，时间戳，错误红色

## 安装与运行

### 环境要求

- Node\.js 18\+

- Rust 环境（Tauri 2 依赖）

### 开发模式

```bash
npm install
npm run tauri dev
```

### 打包构建

```bash
npm run tauri build
```

## 使用说明

1. **新建配置**：点击生成基于 YAML 的默认配置

2. **导入配置**：选择 `\.conf` 格式文件自动合并

3. **修改配置**：点击列表项打开弹窗编辑

4. **搜索**：顶部搜索框实时筛选

5. **另存为**：保存为 `key=value` 格式配置

6. **日志**：点击日志按钮查看操作记录
